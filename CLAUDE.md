# ortho44-2018

Gatsby 1 site (2018) serving historical aerial photos of Loire-Atlantique, deployed on
Netlify from `master` (`ortho44-2018.netlify.app`).

## Build

- Node 10 only (`.nvmrc`), as on Netlify: `nvm use 10 && npm ci && npm run build`.
- Gatsby 1 does not empty `public/` between builds: run `npm run clean` first when the
  build must reflect the current sources (checking a change, counting requests).
- `static/vendor/pmtiles.js` is copied from `node_modules` by `npm run copy-vendor`
  (prebuild / predevelop hooks) and is not tracked by git.

## Data

- Base layers are PMTiles from the `vu-du-ciel` OVH bucket, IGN layers come from
  `data.geopf.fr`; all layers are defined in `src/settings/layers.js`.
- Place search runs in the browser on `static/data/recherche/`. It is regenerated by
  `scripts/export-recherche.py`, which reads the former cg44 Elasticsearch index hosted
  by Makina Corpus: it only works while that index still answers.

## Checking the map in a browser

- The map ignores the wheel until hovered (`leaflet-sleep`): zoom with a double-click
  in Playwright scripts.
- Past `maxNativeZoom`, any width added to a tile is scaled up with the zoom level and
  shows as offsets at tile seams: see the comment in `src/components/SyncedMaps.js`.
